# T-shirt print files – white ink on black shirt

Vector artwork, traced from the supplied PDFs (which contained raster images only),
scaled to actual print size. Artwork is white on a transparent background with no
bleed or margin: the document size equals the artwork size.

| Position | File | Actual size (W x H) |
|---|---|---|
| Front (left chest) | `Front_Mountain-Sunrise_7cm_white.pdf` / `.svg` / `.eps` | 70.0 x 36.2 mm |
| Back | `Back_Algarve-Hikers-Badge_25cm_white.pdf` / `.svg` / `.eps` | 250.0 x 289.4 mm |

- Colour: 100% white (#FFFFFF), single colour, no background object.
- PDF/EPS files look blank in a viewer with a white page background. Use the PNGs in
  `preview/` (300 dpi mock-up on black) to check them, or `proof-black-on-white/`,
  which is the identical artwork filled black for proofing on paper.
- Thinnest line: approx. 1.2 mm on the front, approx. 1.5 mm on the back.
- To print the back at a different size, scale proportionally (e.g. 216 x 250 mm for a 25 cm height).
